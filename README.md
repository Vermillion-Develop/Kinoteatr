# 🎬 CinemaStudio ERP (Kinoteatr)

Современная кроссплатформенная клиент-серверная ERP-система, предназначенная для автоматизации бизнес-процессов, управления этапами кинопроизводства и учета финансовых затрат на съемки.

## 🏗️ Архитектура и структура проекта

Решение спроектировано в рамках **клиент-серверной архитектуры** и разделено на три независимых модуля для обеспечения слабой связанности компонентов:

*   **`KinoTeatrBackground` (Backend Web API):** Высокопроизводительный RESTful API на базе ASP.NET Core. Отвечает за обработку бизнес-логики, работу промежуточного ПО (Middleware), фильтрацию данных и безопасное взаимодействие с реляционной базой данных.
*   **`KinoTeatr` (Desktop-клиент):** Кроссплатформенное десктопное приложение, разработанное на Avalonia UI. Взаимодействие с API построено полностью на асинхронных запросах (`async/await`), что гарантирует отзывчивость интерфейса при работе с тяжелыми операциями ввода-вывода.
*   **`KinoTeatrShared` (Общий слой предметной области):** Легковесная библиотека, содержащая объекты передачи данных (DTO), общие сущности и модели валидации, переиспользуемые как на стороне клиента, так и на сервере.

## 🛠️ Стек технологий

| Слой системы | Технологии и библиотеки |
| :--- | :--- |
| **Backend API** | .NET 8 / 9, ASP.NET Core Web API, паттерн MVC |
| **Доступ к данным** | Dapper (Micro-ORM), оптимизация сырых SQL-запросов |
| **База данных** | PostgreSQL |
| **Интерфейс (UI)** | Avalonia UI (кроссплатформенное ядро), паттерн MVVM |
| **Mvvm Toolkit**| CommunityToolkit.Mvvm (генераторы исходного кода / Source Generators) |
| **Потоки данных** | Асинхронное программирование (`async/await`), маппинг DTO |

---

## 🚀 Ключевой реализованный функционал

*   **Управление кинопроизводством:** Реализован полный цикл CRUD-операций для отслеживания стадий создания фильмов, распределения съемочной группы, актеров и съемочных графиков.
*   **Каскадная фильтрация данных:** Разработана система двойного отбора данных в реальном времени через связанные комбобоксы интерфейса, синхронизированные через MVVM-свойства.
*   **Учет и аудит расходов:** Выделенный модуль финансового учета, позволяющий контролировать операционные издержки студии с динамической группировкой по типам затрат.
*   **Оптимизация уровня данных:** Отказ от избыточных надстроек Entity Framework в пользу кастомных, легковесных SQL-запросов через Dapper для обеспечения максимальной скорости работы с БД.
